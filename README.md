# RobloxScript Telegram Bot (@AsceRobloxScript_bot)

Бот для публикации постов со скриптами в Telegram-канал и автоматической выдачи скриптов по нажатию на кнопку.

## 🚀 Возможности
1. **Авто-выдача скрипта:** Когда подписчик канала нажимает кнопку `[ 🚀 Получить скрипт ]`, бот открывается и сразу выдаёт:
   - Неоновый фирменный баннер RobloxScript
   - Текст: `Привет! Вот держи скрипт для <Игра>:`
   - Код скрипта в специальном блоке (копируется в один клик)
   - Пожелание `Удачи! 🎮`
2. **Умный генератор постов (AI-стилизация):**
   - Название игры автоматически форматируется с заглавных букв (например, `steal an egg` -> `Steal An Egg`).
   - Функционал форматируется в красивый список с эмодзи (`ESP`, `Auto Farm`, `Speed`, `Teleport`).
   - Поддерживает стандартный набор по умолчанию или ввод своих функций.
3. **Прямая публикация в канал:**
   - После создания поста вы можете опубликовать его в канал одной кнопкой `[ 📢 Опубликовать в канал ]`.
4. **Хранение в SQLite:**
   - Все скрипты сохраняются в базу данных с уникальными ключами для дип-ссылок (`s1`, `s2`, ...).

## 🕹 Как пользоваться админ-панелью

1. Откройте диалог с ботом **[@AsceRobloxScript_bot](https://t.me/AsceRobloxScript_bot)** в Telegram.
2. Отправьте команду:
   ```text
   /admin
   ```
   *(Первый пользователь, написавший `/admin`, автоматически становится главным администратором).*
3. **Привяжите канал:**
   - Добавьте бота в ваш канал в качестве **Администратора** (с правом отправки сообщений).
   - В меню бота нажмите `📢 Привязать Telegram-канал` и отправьте юзернейм канала (например: `@my_channel`).
4. **Создайте пост:**
   - Нажмите `➕ Создать пост со скриптом`.
   - **Шаг 1:** Введите название игры (например: `steal an egg`).
   - **Шаг 2:** Нажмите кнопку `⚡ По умолчанию` или напишите свои функции через запятую.
   - **Шаг 3:** Отправьте код скрипта (например: `loadstring(...)()`).
   - Бот сгенерирует пост с неоновой картинкой и кнопкой.
   - Нажмите `[ 📢 Опубликовать в канал ]` — пост сразу появится в вашем канале!

## 🛠 Запуск бота на компьютере

Для запуска бота достаточно запустить файл **`start.bat`** (дважды кликнуть по нему мышкой).
Или через консоль:
```bash
python bot.py
```
